# Dokwang Character Kit · 도광 캐릭터 키트

[한국어](#한국어) · [English](#english)

## 한국어

도광프렌즈 Blender 애드온과 GPT 요청문으로 버추얼 캐릭터를 만들고, Windows 플레이어에서 표정과 동작을 재생합니다.

### 1~15강 실습 시작하기

1. 한·영 통합 실습자료 v1.91.0을 받으세요. [Dokwang_Blender_Practice_v1_91_0_L01-L15.zip](https://github.com/dokwangfriends/dokwang-character-kit/releases/download/v1.0.9/Dokwang_Blender_Practice_v1_91_0_L01-L15.zip)
2. Windows에서 ZIP 전체를 한 폴더에 풀고 `Start_Practice.cmd`를 두 번 클릭하세요.
3. 실습 화면에서 **한국어**를 선택하고 1강을 여세요.

플레이어 조작창 상단의 **옵션**을 누르면 별도 창이 열립니다. 여기서 **출력창 항상 위에 표시**와 **조작창 항상 위에 표시**를 각각 켜거나 끌 수 있습니다. 선택은 다음 실행에도 유지됩니다. 출력창의 가로·세로 비율을 바꿔도 녹색 배경이 창 안쪽 전체를 채웁니다.

조작창 오른쪽 위에서 ‘옵션’ 옆의 ‘도움말’을 누르면 OBS 설정 방법이 별도 창에 열립니다. OBS 아래 ‘소스 목록’에서 캐릭터 윈도우 캡처를 선택하고 Ctrl+E를 누르세요. ‘경계 상자 유형’은 ‘외부 경계에 맞추기’, ‘경계 상자 내 정렬’은 ‘정중앙’을 선택하세요. ‘경계 상자 크기’에는 방송에 원하는 너비와 높이를 입력하고 ‘경계 상자로 자르기’를 체크하세요. 가로와 세로를 5:6으로 정하면 플레이어 창을 어느 방향으로 늘려도 같은 방송 구도를 유지할 수 있습니다.

개발 소스 전체는 위 표의 `Dokwang_Character_Source_v1_0_14.zip`에 들어 있습니다. v1.0.9의 자동 생성 항목 `Source code (zip)`에는 태그를 만들 당시 저장소의 README 한 파일이 들어 있습니다.

**13강에서 추가한 ‘수업 마무리 인사’ 재생하기** — 14강 플레이어에서 13강에 직접 내보낸 GLB를 여세요. 제공 예제로 확인하려면 실습 폴더의 `Run/L13/L13_preview.glb`를 여세요. 14강의 `Run/L14/my_player.glb`에는 기본 동작 11개가 들어 있습니다.

교재 117쪽 QR로도 배포 파일을 찾을 수 있습니다. [최신 릴리스 열기](https://github.com/dokwangfriends/dokwang-character-kit/releases/latest)

## English

Create and animate a virtual character with the Dokwang Friends Blender add-on and GPT prompts, then play its expressions and motions in the Windows player.

### Start lessons 1–15

1. Download the bilingual practice pack v1.91.0. [Dokwang_Blender_Practice_v1_91_0_L01-L15.zip](https://github.com/dokwangfriends/dokwang-character-kit/releases/download/v1.0.9/Dokwang_Blender_Practice_v1_91_0_L01-L15.zip)
2. On Windows, extract the entire ZIP to one folder and double-click `Start_Practice.cmd`.
3. Select **English** in the practice app and open Lesson 1.

### Tools used in the course

| Purpose | Download | How to use it |
| --- | --- | --- |
| Lesson 14 · Windows player v0.8.8 | [Dokwang_Character_Player_Win64_v0_8_8.zip](https://github.com/dokwangfriends/dokwang-character-kit/releases/download/v1.0.14/Dokwang_Character_Player_Win64_v0_8_8.zip) | Extract the entire ZIP and run `DokwangPlayer.exe`. Open `my_player.glb` in the player to play its motions. |
| Lesson 15 · Blender add-on v0.35.3 | [Dokwang_Character_Addon_0_35_3.zip](https://github.com/dokwangfriends/dokwang-character-kit/releases/download/v1.0.9/Dokwang_Character_Addon_0_35_3.zip) | In Blender, choose **Install from Disk** and select the ZIP. Attach the same ZIP when the lesson asks you to give the add-on to GPT. |
| Development · Add-on and player source v1.0.14 | [Dokwang_Character_Source_v1_0_14.zip](https://github.com/dokwangfriends/dokwang-character-kit/releases/download/v1.0.14/Dokwang_Character_Source_v1_0_14.zip) | Download this ZIP to build the software or inspect the code. The extracted `dokwang-character-kit` folder contains `addon`, `player`, and `tools`. |

Open **Controls → Options** to bring up a separate window. Select **Keep output window on top**, **Keep controls window on top**, or both. The player remembers each setting. The green background fills the output window when you resize it.

Click Help next to Options at the top right of Controls to open the OBS guide. In OBS Sources, select the character Window Capture and press Ctrl+E. Set Bounding Box Type to Scale to outer bounds and Alignment in Bounding Box to Center. Under Bounding Box Size, enter the width and height you want on air, then check Crop to Bounding Box. Choose a 5:6 width-to-height ratio to keep the same framing when resizing the player in either direction.

For the complete development source, use `Dokwang_Character_Source_v1_0_14.zip` in the table above. The automatically generated `Source code (zip)` for v1.0.9 contains only the repository README as it stood when the tag was created.

**Play the closing greeting added in Lesson 13** — In the Lesson 14 player, open the GLB you exported in Lesson 13. To use the supplied example, open `Run/L13/L13_preview.glb` in the practice folder. The Lesson 14 sample at `Run/L14/my_player.glb` contains the 11 standard motions.

The QR code on page 117 of the Korean textbook also opens the downloads. [View the latest release](https://github.com/dokwangfriends/dokwang-character-kit/releases/latest)
