## 한국어

도광프렌즈 Blender 애드온과 GPT 요청문으로 버추얼 캐릭터를 만들고, Windows 플레이어에서 표정과 동작을 재생합니다.

### 1~15강 실습 시작하기

1. 한·영 통합 실습자료 v1.91.0을 받으세요. [Dokwang_Blender_Practice_v1_91_0_L01-L15.zip](https://github.com/dokwangfriends/dokwang-character-kit/releases/download/v1.0.9/Dokwang_Blender_Practice_v1_91_0_L01-L15.zip)
2. Windows에서 ZIP 전체를 한 폴더에 풀고 `Start_Practice.cmd`를 두 번 클릭하세요.
3. 실습 화면에서 **한국어**를 선택하고 1강을 여세요.

## English

Create and animate a virtual character with the Dokwang Friends Blender add-on and GPT prompts, then play its expressions and motions in the Windows player.

### Start lessons 1–15

1. Download the bilingual practice pack v1.91.0. [Dokwang_Blender_Practice_v1_91_0_L01-L15.zip](https://github.com/dokwangfriends/dokwang-character-kit/releases/download/v1.0.9/Dokwang_Blender_Practice_v1_91_0_L01-L15.zip)
2. On Windows, extract the entire ZIP to one folder and double-click `Start_Practice.cmd`.
3. Select **English** in the practice app and open Lesson 1.

### Tools used in the course

| Purpose | Download | How to use it |
| --- | --- | --- |
| Lesson 14 · Windows player v0.8.3 | [Dokwang_Character_Player_Win64_v0_8_3.zip](https://github.com/dokwangfriends/dokwang-character-kit/releases/download/v1.0.9/Dokwang_Character_Player_Win64_v0_8_3.zip) | Extract the entire ZIP and run `DokwangPlayer.exe`. Open `my_player.glb` in the player to play its motions. |
| Lesson 15 · Blender add-on v0.35.3 | [Dokwang_Character_Addon_0_35_3.zip](https://github.com/dokwangfriends/dokwang-character-kit/releases/download/v1.0.9/Dokwang_Character_Addon_0_35_3.zip) | In Blender, choose **Install from Disk** and select the ZIP. Attach the same ZIP when the lesson asks you to give the add-on to GPT. |
| Development · Add-on and player source v1.0.9 | [Dokwang_Character_Source_v1_0_9.zip](https://github.com/dokwangfriends/dokwang-character-kit/releases/download/v1.0.9/Dokwang_Character_Source_v1_0_9.zip) | Download this ZIP to build the software or inspect the code. The extracted `dokwang-character-kit` folder contains `addon`, `player`, and `tools`. |

For the complete development source, use `Dokwang_Character_Source_v1_0_9.zip` in the table above. The automatically generated `Source code (zip)` for v1.0.9 contains only the repository README as it stood when the tag was created.

**Play the closing greeting added in Lesson 13** — In the Lesson 14 player, open the GLB you exported in Lesson 13. To use the supplied example, open `Run/L13/L13_preview.glb` in the practice folder. The Lesson 14 sample at `Run/L14/my_player.glb` contains the 11 standard motions.

The QR code on page 117 of the Korean textbook also opens the downloads. [View the latest release](https://github.com/dokwangfriends/dokwang-character-kit/releases/latest)
