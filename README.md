# Dokwang Character Kit

Create and animate a virtual character with the Dokwang Friends Blender add-on, Windows character player, and GPT prompts.

## Download

[Download the latest release](https://github.com/dokwangfriends/dokwang-character-kit/releases/latest)

For the course, download the ZIP ending in `_Offline.zip` under **Assets**. Extract the entire ZIP and open `START_HERE.txt` for instructions in English or Korean. The asset with `GitHub_Source` in its name contains the project source.

## What's new in v1.0.6

Blender add-on 0.35.3 can preview extra actions on characters with compatible NLA tracks and include them alongside the 11 standard motions when exporting a GLB. The kit includes updated English and Korean prompts and the offline Windows x64 player 0.8.2.
